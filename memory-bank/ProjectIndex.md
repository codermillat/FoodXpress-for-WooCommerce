# Project Index: FoodXpress for WooCommerce

## 1. High-Level Overview
A modular, single-restaurant delivery management plugin for WooCommerce. It handles the entire delivery lifecycle, from checkout to the customer's door, with features like delivery zones, distance-based fees, live location pickup, and a dedicated delivery boy view. The system is designed to be simple, robust, and reliant on an external mapping service API for its core geolocation features.
