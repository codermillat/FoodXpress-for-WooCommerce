## Zomato/Swiggy-style checkout: map pin + single address field (v1.2.2)

**Model:** Step 1 stays as-is (search, "Use My Location", draggable pin, read-only selected-location line — already Swiggy-like). Step 2 collapses from 5 structured fields to **one required "House / Flat / Building No." field** + optional landmark + existing optional delivery instructions, mirroring Swiggy's "Complete address*" + "Landmark (optional)". The fee engine is untouched (it runs on pin coordinates only). checkout.js needs **zero changes** — verified it never touches the structured fields.

### 1. `includes/class-fxw-checkout.php` — new Step 2 form
Replace the five `woocommerce_form_field` calls (lines 104–146) with:
- `fxw_address_details` — required text, `form-row-wide`, label "House / Flat / Building No.", placeholder "e.g., Flat 4B, House 25, Tower A, Block 2" (Swiggy-style single line). Prefill from `$saved_profile['address_details']`.
- `fxw_landmark` — optional text (existing key, so nothing downstream changes), prefill from `$saved_profile['landmark']`.
- Keep `fxw_delivery_instructions` textarea and the `fxw_save_address` checkbox as-is.

### 2. `includes/class-fxw-checkout-handler.php`
- **`validate_delivery_zone()` (289–300):** replace the two required-field checks (`fxw_house_flat_no` + `fxw_society_building`) with one check on `fxw_address_details` (required, min ~5 chars after trim).
- **`save_delivery_details_to_order()` (187–227):** read `fxw_address_details` + `fxw_landmark`; write `_fxw_address_details` and `_fxw_landmark` order meta; compose `_fxw_delivery_address` as `details` + optional `" (Landmark: …)"` — existing key, so the admin meta box and delivery-dashboard template keep working unchanged. Stop writing the 4 obsolete field metas. Also set the order's billing/shipping `address_2` to the details line so `get_formatted_shipping_address()` (used by the receipt template and emails) shows the exact flat/house info.
- **`save_customer_address()` (151–171) — fix the dead save path:** the current gate requires `$_POST['fxw_location-search-input']` / `$_POST['fxw_delivery_address']`, which are never submitted (one input has no `name`, the other isn't rendered) — the `_fxw_delivery_profile` user meta is never written today. New gate: run only when the `fxw_save_address` checkbox is checked (finally honoring the existing UI), saving `address_1/2, city, state, postcode, country, lat, lng, address_details, landmark, distance_data`. This also revives the map pre-fill for returning customers (`checkout-maps.php:167` localizes from this profile) and Step 2 prefill.
